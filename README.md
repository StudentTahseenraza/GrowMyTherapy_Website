# 🌿 Dr. Maya Reynolds, PsyD — Therapist Website

A production-ready, multi-page therapist website built with **Next.js 15 + Tailwind CSS** for the **GrowMyTherapy Stage 2 Internship Assignment**.

The project recreates the overall layout, navigation structure, responsiveness, and user experience of the **Conejo Valley Counseling** homepage while redesigning it into a completely new website for **Dr. Maya Reynolds, PsyD**, an imaginary licensed clinical psychologist based in **Santa Monica, California**.

The redesign focuses on **modern UI/UX, local SEO, accessibility, responsive design, and emotionally safe copywriting** for adults seeking therapy.

> **Status:** Production-ready • Responsive • SEO Optimized • Accessible • Vercel Ready

# 🚀 Getting Started

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```

Visit:

```
http://localhost:3000
```

## Build Production Version

```bash
npm run build
```

## Start Production Server

```bash
npm run start
```
